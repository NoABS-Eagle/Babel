# Частотник для ООО «Ирбис», ревизия с абсолютным энкодером

## Аппаратная часть:
  * STM32F302RBT6
  * Входы/выходы:
    * Силовые:
      * Вход питания, 2 клеммы
      * Двигатель, 3 клеммы
      * Выход на лампу-строб, 2 клеммы
    * Слаботочные:
      * Пост внутренний, 4 клеммы
      * Пост внешний, 4 клеммы
      * Радар внутренний, 4 клеммы
      * Радар внешний, 4 клеммы
      * ДЗК, 2 клеммы
      * Световая завеса (они же — фотодатчики), 4 клеммы
      * Радиуправление, 4 клеммы
      * Внутренняя магнитная петля, 4 клеммы
      * Внешняя магнитная петля, 4 клеммы
      * Замок, 2 клеммы
      * 485 для энкодера — 4 клеммы
      * 485 для чего-то ещё — 4 клеммы
  * Шунт для ограничения максимального тока через движок, LRP12FTDRR020
  * Двухэтажные клеммники:
    * DG127A-5.08-06P-14-00AH
    * DG127A-5.08-04P-14-00AH
